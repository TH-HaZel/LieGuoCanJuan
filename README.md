# 列国残卷：房间与基础交互测试

需要 Node.js 18 或更新版本，无须安装依赖。在本目录执行 `npm start`，本机访问 <http://localhost:3000>。现有房间框架也允许同一局域网的设备连接；多人使用同一电脑时，可用独立浏览器窗口或配置文件分别加入房间。

当前可测试：创建或加入 $2 \sim 6$ 人房间；选择唐朝初始武将和两名主牌组武将；开局发牌、每回合摸牌、手牌上限、弃牌堆洗回、黄金收入、部署手牌武将和结束回合。测试允许多名玩家选择唐朝。公共牌暂用默认组合：$18$ 张唐朝技能牌、$20$ 张公共牌和 $2$ 张武将牌构成 $40$ 张主牌组。

本版仍是基础交互，不是完整对战版：尚无自定义公共牌组与保存、额外武将购买、撤回、卡牌效果、战争、外交、冷却递减、中立资源争夺和胜负判定。部署费用暂为 $1$ 金；黄金在各玩家自己的回合开始时发放。所有对局状态保存在服务器内存中，重启后清空。

服务器保存各玩家私有手牌，仅向本人发送；请妥善保管房间身份令牌。本原型还不是正式上线版本。

## 同一台电脑测试

打开首页的“单机轮流测试”，选择 $2\sim 6$ 名玩家，并为每位玩家填写昵称和选择武将。开始后通过交接页面进入当前玩家界面；结束回合后将显示下一位玩家的交接页面。该模式复用本地房间服务，服务器重启后对局丢失；隐私遮罩只防止日常操作时直接看到上一位玩家的手牌，并不能防止通过浏览器开发者工具或会话存储读取信息。
