# 列国残卷：本地联机骨架

需要 Node.js 18+，不需要安装依赖。在文件夹里运行 `npm start`，本机访问 http://localhost:3000；局域网其他电脑访问 http://服务器电脑IP:3000。

创建或加入房间（2～6 人），房主开始游戏，每位玩家使用 40 血的初始国家、10 黄金和 0 基础防御。轮到自己的玩家可以结束回合，下一位玩家获得 2 黄金。暂定第一位玩家首次回合开始也获得 2 黄金。只有房主能开始，只有当前玩家能结束回合。

卡牌内容和初始武将尚未实现；战争、外交、交易、冷却、中立资源与胜负判定仍需补齐准确规则。房间数据在服务器内存中，服务器重启后清空。

server.js 负责网络入口；server/rooms.js 管理房间；game/player.js 和 game/game.js 保存玩家及回合规则；public/ 是客户端页面。
