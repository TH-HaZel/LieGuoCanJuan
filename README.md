# 《列国残卷》规则

## 开局与牌组

- 2～6 人，每人选择一名初始武将和两名牌组武将。唐朝初始国家生命为 35，独立国家防御为 0。
- 加入房间后在大厅等待，至少 2 人时由房主开始。开局随机排列座次，按该顺序轮流行动。
- 每人牌组共 40 张：18 张唐朝技能牌、20 张公共牌、2 张武将牌。
- 公共牌按攻击增益 5、防御增益 5、能力 3、状态 4、解场 3 构筑。同名牌上限：高级 1 张、中级 2 张、低级 4 张。
- 开局抽 5 张牌，每回合抽 1 张；手牌上限 10 张，超出的新牌进入弃牌堆。牌堆空时将弃牌堆洗回。

## 回合与黄金

- 每位存活玩家依次行动，全部行动后进入中立资源争夺。
- 第 n 大轮的基础收入为 n 金，最多 7 金；唐朝额外获得 1 金。收入在自己的回合开始时获得。
- 回合内可以使用符合条件的牌、部署或撤回武将，并最多购买一名武将。宣战、武将交易和申请加入同盟共用一次主要行动。

## 武将与战争

- 同时最多部署 5 名武将；购买和部署分别支付费用。武将生命降至 0 时濒死，失去自身技能；濒死后再次战败则阵亡。
- 武将参战后进入冷却，在所属玩家的回合结束时递减；参战的当前回合结束不递减。
- 宣战后，防守方可以谈判或迎战。双方可选择可出战的武将；防守方也可选择国家硬抗，战力只计算独立国家防御及卡牌加成，不加入国家生命。
- 进攻战力为武将攻击力及加成，扣除距离惩罚；防守战力为武将防御力及加成。同一方多名武将参战时，按人数扣除协同惩罚。盟友援军按对应攻防的一半向下取整加入战力。
- 进攻方战力高时，防守国家损失双方战力差，防守武将战败；防守方战力高时，进攻武将战败，防守方可追击或索赔。平局双方武将不因战败扣血。国家硬抗不能追击或索赔，也不能请求盟友增援。
- 战败武将通常损失 1 点生命；普通战争参战援军不承担战败扣血。援军正常进入冷却。
- “鸣金收兵”使目标一方直接失败并使其参战武将扣血，参战援军不扣血。“识破”可抵消鸣金收兵；被抵消或没有目标的牌仍消耗费用。

## 同盟与交易

- 申请加入同盟需表决并支付入盟费；盟友可请求一名可出战武将增援。
- 有可用武将却拒绝增援，或主动攻击盟友，属于背叛：退出同盟、失去 10 金，并在当前及下一大轮不能结盟；下一次实际战争或中立争夺战力减 2。
- 和平退出需其余盟友至少半数同意，不消耗主要行动。同盟成员每回合可赠金一次，不消耗主要行动。
- 双方可以用武将和黄金交易；场上或手牌中的武将均可交易。双方同意后，武将进入新持有者手牌，保留生命、冷却、增益、负面状态和经验；交易后手牌不能超过上限。

## 中立资源

- 默认资源池包含 20 份黄金和 20 张公共牌，每大轮公开 1 个资源。灭国回收的存活武将及符合条件的公共牌会进入资源池。
- 玩家选择资源和主将，可以谈判退出；参战名单确定后，每人可秘密派一名本国武将增援，再按规则使用争夺牌。
- 按攻击战力比较，唯一最高者获得资源；最高并列时无人获得。失败方主将通常损失 1 点生命，增援不承担普通战败扣血；参战武将进入冷却。
- 战争经验最多 3 份，可用于清除冷却或在参战时增加对应战力。
